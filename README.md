# Rick and Morty Dashboard

Proyecto final integrador del curso de React (Talendig).

## Idea
Una aplicación web para explorar los personajes de Rick and Morty, ver el detalle de cada uno y guardar los favoritos con una nota personal.

## Caso
Caso A: los datos principales vienen de una API pública. Lo que hace el usuario (personajes guardados y notas) se guarda en `localStorage`.

## API
- Lista: https://rickandmortyapi.com/api/character (los personajes vienen dentro de `results`)
- Detalle: https://rickandmortyapi.com/api/character/:id

## Vistas
| Ruta | Vista |
|---|---|
| `/` | Inicio |
| `/personajes` | Lista de personajes con buscador |
| `/personajes/:id` | Detalle de un personaje |
| `/guardados` | Personajes guardados con notas |
| `*` | Página 404 |
